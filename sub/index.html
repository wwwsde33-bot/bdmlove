Guide 01 환생

▼
[ 단계별 환생 권장 루트 ]
  • 1번째 환생: 120레벨 진행 (이후 환생포인트로 하이퍼 포인트 1 투자)
  • 2번째 환생: 180~190레벨 진행 (하이퍼 포인트 3 투자, 남은 포인트는 데미지 전부 투자)
  • 3~5번째 환생: 200레벨 진행 (크확 50 달성 후, 남은 포인트는 데미지/경획 분산 투자)
  • 5번째 환생 이후: 200레벨 이상에서 1업당 10분 넘어갈 시 즉시 환생 (데미지/경획 100레벨 도달 이후에는 데미지만 투자)
💡 사냥터 및 데미지 최적화 팁
효율적인 투자를 위해 직접 테스트가 필요합니다.
현재 사냥터 1킬, 다음 사냥터 2킬, 다다음 사냥터 3킬인 상황이라면?
→ 다다음 사냥터가 2킬이 될 때까지 데미지를 찍으세요.
→ 2킬 달성 시 잠시 경획을 올리고, 다음 3킬 사냥터가 2킬이 될 때까지 다시 데미지를 찍는 과정을 반복합니다.
[ 환포 수급 ]
  • 첫째, 하루 15회 환생을 꼬박꼬박 완료해야 합니다.
  • 둘째, 자고 일어나서 1회 환생이후 자정 전까지 남은 시간을 계산하여 효율적으로 14회를 마칩니다.
※ 1킬 사냥보다 다음 사냥터가 존재할 시 다음 사냥터 2킬 사냥이 경험치를 더 잘 먹습니다. ※ 5번째 환생 이후 업당 10분넘어갈시 환생은 하루 환생 15번을 안했을때 기준입니다. ※ 15회 환생 관련 모르는 게 있을 시 사랑 개인 DM 주시면 알려드립니다.

Guide 02 환생포인트

▼
[ 우선 순위 ]
  • 하이퍼 포인트 4
  • 크확 100% 맞추기 (도감 획득 수치를 제외한 본인 크확 파악 후 부족한 만큼 투자)
  • 데미지 100
  • 경획 100
  • 이후 데미지 우선순위로 투자하되, 경획과 적절히 분산 투자
  • 자사(자동사냥): 개인의 자유이나, 효율이 낮은 극초반 투자는 피하는 것을 권장
※ 메획/아획은 절대 투자하지 않습니다.
※ 1차 스탯을 전체 마스터해야 2차 스탯을 투자할 수 있습니다.
(단, 크확 50레벨 및 하이퍼 포인트 4레벨 달성 시 해당 스탯은 마스터로 취급되어 2차 스탯 개방이 가능합니다.)

[ 최종 환생 포인트 효율적으로 찍는 트리 ]
  • 1차 스탯: 데미지 하이퍼 → 크확 → 데미지 → 경획 → 자동사냥 → 아획 → 메획
  • 2차 스탯: 크댐 50 → 방무 50 → 주스탯 20 → 크댐 M → 방무 M → 주스탯 M
※ 분산투자를 권장하므로 특정 레벨 추천은 없습니다!
※ 아획 메획은 절대 찍지 않습니다. (데미지, 경획 마스터 이후 찍을 게 없을 때 찍기)
※ 1차 스탯을 다 찍어야 2차 스탯 레벨업이 가능합니다.
※ 주스탯은 투력은 잘 올라가지만 실제 데미지가 많이 증가하지는 않습니다.

[ 장비 강화 슬롯 ]
  • 전체 10강 → 전체 20강 → 무기 50강 → 전체 30강 → 무기 60강
  • 상하의 50강 → 장갑 40강 → 모자 40강 → 신발 40강 → 상하의 60강
  • 장갑 50강 → 모자 50강 → 신발 50강 → 망토 40강 → 귀골 40강
  • 장갑 60강 → 모자 60강 → 신발 60강 → 망토 50강 → 귀골 50강
  • 눈장얼장 40강 → 망토 60강 → 귀골 60강 → 눈장얼장60강

[ 아케인 심볼 ]
  • 6부위 전체 3~5강 이후 방치
  • 장비강화칸 전체 40강 이상일때 심볼 전체 7~8레벨
  • 장비강화칸 전체 마스터시 분산투자로 전체 풀강화
※ 효과가 강화칸보다 한참 안 좋기에 장비 강화에 우선 투자해야 해서 방치합니다.

Guide 03 다이아

▼
[ 효율적인 다이아 사용 우선 순위 ]
  • 펫 성장: 펫 6레벨 도달 이후, 레전더리 펫 1마리를 뽑을 때까지 우선적으로 투자합니다.
  • 코스튬 보유효과: 코스튬 보유효과를 통해 주스탯 1500을 달성할 때까지 코스튬 구매 (무기 코스튬 구매 추천)
💡 코스튬 팁
코스튬 메뉴 클릭 후 좌측 상단의 ? 아이콘을 누르면 현재 적용 중인 보유효과를 확인할 수 있습니다.
※ 경험치 쿠폰 2배를 다이아로 구매하는 것은 효율이 낮아 권장하지 않습니다. ※ 자유 전직권 및 환포 초기화권은 가급적 구매하지 마세요.

Guide 04 꿀팁

▼
[ 던전 및 장비 ]
  • 던전 티켓: 매일 00시 기준으로 5장까지 리필됩니다. (남은 장수에 상관없이 총 5장이 되도록 충전되니 매일 모두 소진하세요.)
  • 환생의 불꽃: 장비 기본 능력치의 최대 50%까지 부여됩니다. (예: 기본 주스탯 10, 공 50인 경우 환불 최대치는 주스탯 5, 공 25)
[ 개인 사냥터 활용 (파티 던전) ]
겹사가 싫다면?
메뉴 - 파티 - 파티 생성 - 원하는 사냥터 선택 - 파티 채널 이동을 이용하세요. 파티원(또는 본인 혼자)만 입장할 수 있는 쾌적한 사냥이 가능합니다.
[ 주간 보스 최적화 ]
  • 코인 수급: 주간 보스는 최대 1000코인까지 획득 가능하며, 1억 데미지당 1코인이 지급됩니다.
  • 딜링 최적화 팁:
    • 재접속 후 사냥터에 들어가지 말고 로비에서 스킬을 정비하세요.
    • 온오프 스킬을 미리 켜고, 스킬 배치칸에 1~4차 액티브 스킬을 전부 배치합니다.
    • 모든 스킬을 동시에 꾸욱 누르면 씹힘 없이 모든 스킬이 동시에 나갑니다.
※ 사냥터에 진입한 후 여러 스킬을 사용하거나, 재접속 없이 스킬을 동시에 누르면 스킬이 씹힐 수 있습니다.

Guide 06 뉴비 자주 묻는 질문(FAQ)

▼
1. 다른사람은 텔레포트하면서 싸우는데 저는 제자리에서 싸워요
  • 월드코인 밥똥멤버스 650월코(현금 약5천원) 구매시 자동사냥텔포가 생깁니다
2. 장비 뭐 껴요?
  • 커닝타워 150제 상하의 / 파괴된 헤네시스 160제 모자 무기 신발 장갑 착용
  • 모라스 200제 전부위 착용
  • 장신구&망토는 에픽던전에서 눈장 얼장 귀걸이 망토 4부위 획득가능
3. 에픽던전은 언제 깰수있어요?
  • 버섯의성 = 1~2M
  • 아랫마을 = 5~7M
  • 폭군의성채 = 8~11M
  • 엘린숲 = 20~22M
※ 직업, 현재 장비상태, 도감상태등 다양한 이유때문에 정확하진 않습니다 대략 저정도다 라는것만 알면 되고 저정도에서 안깨지면 무기에서 방무를 챙기고 다시 재시도해보세요
4. 퀘스트 라이딩 길드 이거 언제열려요?
  • 아직은 없습니다 현재 미구현 컨텐츠입니다
5. 주스탯 부스탯 이거 뭐예요?
  • 원래는 1업당 5포인트씩 지급되며 직접 주스탯 또는 부스탯을 찍었어야했는데, 현재는 부스탯이 효과가 없다시피해서 주스탯만 찍기때문에 자동으로 찍히게끔 바꿔놓은 상태입니다
6. 장비 옵션 뭐 뽑아야되나요?
  • 무기 제외 주스탯이 제일 좋습니다 1티어 주주주 2티어 주주올 3티어 주올올 4티어 올올올
  • 무기는 딱 정해져있지가 않습니다 방무 공퍼 보공 데미지 4개 잘 섞어서 3줄 띄워서 사용하세요
